Bilingual Selector — Port 8002
Language detection · in-place switch · no reconnect
Call connects on :8002
Sara (bilingual greeting)
"To continue in English, say English. اردو میں جاری رکھنے کے لیے اردو کہیں۔"

Two detection signals are combined. Text-pattern detection runs on the transcript; Whisper audio-language detection is used as ground truth when text-pattern returns no match (handles hallucinated Latin words from Urdu speech like "or do" → still detects audio is Urdu).

User says "English"

  • Pattern match: english
  • Sara: "Sure!"
  • action: switch_language · en
  • Agent flips: language="en"
  • _fast_engine.language="en"
  • TTS → en-US-AriaNeural
  • LLM plays English greeting
  • Call continues as English flow

User says "اردو" / "Urdu"

  • Pattern: Urdu chars / "urdu" text
  • Whisper: audio_lang = "ur" (fallback)
  • Sara: جی ضرور!
  • action: switch_language · ur
  • Agent flips: language="ur"
  • _fast_engine.language="ur"
  • TTS → ur-PK-UzmaNeural
  • LLM plays Urdu greeting
  • Call continues as Urdu flow

If unclear: Sara says "سمجھی نئیں ... اردو یا English کہیں / Please say Urdu or English" and waits. No disconnection at any point — same WebSocket throughout.

Gemini → Groq → Ollama
1
Gemini
gemini-3.5-flash · up to 6 API keys rotating · skipped for English
UR RO
timeout 12s
On 503 / timeout / quota exhausted → try next key → all keys fail → Groq
2
Groq
llama-3.1-8b-instant · fast cloud, rarely overloaded
EN UR RO
timeout 10s
On failure / timeout → Ollama
3
Ollama (local)
Configured model · GPU → CPU fallback on VRAM error · primary for English
EN UR
no timeout

Gemini daily-quota exhausted keys are cached per process and skipped on future calls. Groq was added after Gemini 503 incidents caused ~2-minute waits; Groq typically responds in 1–2s.

Key Components
What handles what
Component Handles When it fires
Fast Engine FAST Name, phone, date, time — structured inputs with clear answers Flow state is one of: collect_name · collect_phone · collect_date · collect_time · confirm_booking
LLM Agent LLM Symptoms, doctor recommendation, corrections, confusion, confirmation summary Fast Engine returns None, or confirmation chain triggered
_play_confirm_reminder() HARDCODED Fee amount + WhatsApp screenshot instruction + "confirm?" question Always fires after action: confirm — LLM never speaks fee
Inactivity Monitor Auto-ends call if patient goes silent after booking flow_state = post_booking + 10 seconds of no audio
Micro-ack Cache Instant filler ("جی..." / "Okay...") while LLM generates Every turn before LLM response starts; randomly picks one variant
Barge-in Guard Suppresses VAD while Sara is playing audio Active for estimated playback duration + 0.6s margin
Greeting Cache Serves pre-synthesized greeting audio on repeat calls MD5 hash of greeting text → data/cache/greeting_*.bin. Skipped for bilingual greetings.

Situation Sara's response Mechanism
